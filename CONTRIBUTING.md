# Contributing

Thank you for helping keep this list useful and current.

## What belongs here

A resource should:

- directly support LXC, LXD, or Incus;
- be useful beyond a single personal setup;
- have clear documentation and a working canonical URL;
- be actively maintained, or remain reliable and relevant despite infrequent changes;
- add something not already covered by an existing entry.

Archived, abandoned, insecure, or substantially outdated resources may be removed. General container, virtualization, or homelab projects belong only when they provide a meaningful LXC, LXD, or Incus integration.

## Adding a resource

1. Choose the most specific existing section.
2. Link to the canonical project or documentation page.
3. Use the official project name and a concise, factual description.
4. Check that the link resolves without requiring authentication.
5. Keep the pull request focused and explain why the resource is useful.

Use this format:

```markdown
- [Project name](https://example.com/) — One-sentence description ending with a period.
```

## Updating or removing a resource

Please update moved URLs and renamed projects when a maintained successor exists. When removing a resource, briefly note whether it is archived, unavailable, superseded, or no longer compatible with current releases.
